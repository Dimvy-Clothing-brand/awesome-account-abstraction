This repository is a fork of the [4337Mafia/awesome-account-abstraction](https://github.com/4337Mafia/awesome-account-abstraction) repository. It aims to consolidate and share knowledge and tools related to **Account Abstraction** in Ethereum, focusing on **EIP-4337**. Whether you're a developer, researcher, or enthusiast, this list provides valuable resources to deepen your understanding of account abstraction.

## What is Account Abstraction?

Account Abstraction is a concept in Ethereum that allows for more flexible and programmable accounts. By abstracting the complexities of externally owned accounts (EOAs) and smart contract accounts, it enables use cases such as:

- Custom account recovery mechanisms
- Gasless transactions
- Multi-signature wallets
